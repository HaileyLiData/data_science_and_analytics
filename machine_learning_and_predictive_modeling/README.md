# Machine Learning and Predictive Modeling

This repository contains analytical modeling exercises and probabilistic learning workflows focused on Bayesian inference, predictive analytics, and statistical learning.

Key areas include:

- predictive modeling and probabilistic inference
- Bayesian statistics and posterior estimation
- multilevel regression and partial pooling
- likelihood-based estimation (MLE / NLL)
- entropy, KL divergence, and cross-entropy
- model validation and predictive evaluation
- Bayesian workflow using brms and MCMC
- applied statistical learning in R

The work emphasizes uncertainty-aware modeling, probabilistic reasoning, and predictive decision-making using modern statistical and machine learning approaches.

## Academic Context

Projects and analytical exercises were completed as part of **MSE718 – Statistical Methods for Data Analytics** in the Master of Management Sciences (MMSc) program at the University of Waterloo.
