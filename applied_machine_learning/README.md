# Applied Machine Learning

This repository contains practical machine learning workflows and analytical modeling exercises focused on supervised learning, predictive modeling, and model evaluation.

Key areas include:

- supervised and unsupervised learning
- classification and clustering methods
- feature engineering and data preprocessing
- predictive modeling workflows
- model evaluation and validation
- practical ML implementation in Python
- end-to-end analytical pipelines

The work emphasizes practical machine learning implementation, data-driven prediction, and scalable analytical workflows for real-world applications.

## Academic Context

Projects and analytical exercises were completed as part of **MSE623 – Introduction to Machine Learning** in the Master of Management Sciences (MMSc) program at the University of Waterloo.
