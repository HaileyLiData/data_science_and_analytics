# Statistical Modeling and Data Analysis

Coursework and analytical exercises focused on statistical modeling, quantitative inference, regression analysis, and data-driven analysis using R.

## Key Areas

- regression modeling
- statistical inference
- quantitative data interpretation
- hypothesis testing
- model evaluation
- analytical workflows

## Tools

- R
- statistical modeling
- data visualization

## Academic Context

Materials were developed through graduate-level coursework in quantitative data analysis, including MSE609 – Quantitative Data Analysis in the Master of Management Sciences (MMSc) program at the University of Waterloo.
