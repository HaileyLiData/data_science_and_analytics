# Natural Language Processing and Text Analytics

This repository contains NLP workflows and text analytics projects focused on language modeling, semantic representation, and applied natural language understanding.

Key areas include:

- natural language processing (NLP)
- text mining and semantic analysis
- text classification and document modeling
- embeddings and vector representations
- language modeling workflows
- LLM-related analytical pipelines
- applied text analytics using Python

The work emphasizes language representation, semantic reasoning, and practical NLP workflows for AI-driven text analysis applications.

## Academic Context

Projects and analytical exercises were completed as part of **MSE641 – Text Analytics** in the Master of Management Sciences (MMSc) program at the University of Waterloo.
