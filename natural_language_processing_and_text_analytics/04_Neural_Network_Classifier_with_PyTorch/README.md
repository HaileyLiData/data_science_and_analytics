# Neural Network Classifier with PyTorch

Neural network classification workflow using PyTorch and Word2Vec document embeddings for Amazon review sentiment analysis.

The project implements a fully-connected feed-forward neural network and evaluates the impact of activation functions, L2 regularization, dropout, and early stopping on classification performance.

## Project Overview

This project builds a complete neural network classification pipeline using PyTorch.

## Neural Network Workflow

### Step 1 — Load Word2Vec Embeddings

Load the trained Word2Vec model generated in Module 03.

Input model:

* word2vec_model.model

The embedding model provides dense vector representations for words learned from Amazon review data.

---

### Step 2 — Create Document Embeddings

Each review document is converted into a fixed-length vector representation.

Document embeddings are generated by averaging all Word2Vec vectors contained in the document.

Example:

```text
Review:
["this", "movie", "is", "great"]

↓

Average Word Vector

↓

Document Embedding (100 dimensions)
```

This approach creates a consistent feature representation for all documents.

---

### Step 3 — Build Neural Network Architecture

A fully-connected feed-forward neural network is implemented using PyTorch.

Architecture:

```text
Input Layer (Word2Vec Embeddings)

↓

Hidden Layer (128 Neurons)

↓

Activation Function

↓

Dropout Layer

↓

Output Layer (2 Classes)
```

Output classes:

* Positive Review
* Negative Review

---

### Step 4 — Train Models with Different Activation Functions

Three activation functions are evaluated:

* ReLU
* Sigmoid
* Tanh

Each activation function is trained independently and compared using validation accuracy.

---

### Step 5 — Hyperparameter Tuning

The project evaluates different combinations of:

* L2 Regularization
* Dropout Rate

Experimental configurations:

| Activation | L2 Regularization | Dropout |
| ---------- | ----------------- | ------- |
| ReLU       | 0.001             | 0.3     |
| ReLU       | 0.01              | 0.3     |
| ReLU       | 0.001             | 0.5     |
| Sigmoid    | 0.001             | 0.3     |
| Sigmoid    | 0.01              | 0.3     |
| Tanh       | 0.001             | 0.3     |
| Tanh       | 0.01              | 0.3     |

Validation performance is used for model selection.

---

### Step 6 — Early Stopping

Early stopping is implemented to reduce overfitting.

Training stops automatically when validation performance fails to improve for multiple epochs.

Benefits:

* reduced overfitting
* faster training
* improved generalization

---

### Step 7 — Evaluate Final Models

The best configuration for each activation function is evaluated on the test dataset.

Evaluation metric:

* Accuracy

Generated output files:

* hyperparameter_tuning.csv
* results.csv

---

### Step 8 — Save and Upload Models

The project saves:

* relu.pth
* sigmoid.pth
* tanh.pth
* best_model.pth

Models are uploaded to the university model server and validated through automated grading.
